# ST-TTS · 角色对白

版本 0.2.0，SillyTavern 浏览器扩展。

用一部手机式配音面板管理 Fish Audio、MiniMax 和 ElevenLabs。不同角色可以使用不同引擎，中文译文供阅读，完整原语言台词供语音生成。

## 安装与更新

在酒馆「扩展 → 安装扩展」粘贴：

https://github.com/hey8v0/ST-TTS

已经安装的用户，在扩展管理中更新 ST-TTS，然后刷新酒馆页面。打开「ST-TTS · 角色对白 → 打开配音设置」即可进入手机桌面。无需额外安装 Termux 服务或 Node 模块。

## 手机桌面

- **角色**：新增、编辑、删除角色配音；三家引擎各自记住音色和模型。音色可手动填写或读取列表，角色语言可覆盖默认语言。
- **引擎**：各家独立的模型、密钥和参数页面。语速、声音、输出格式、词典和参考音频等按模型能力显示；小 i 提供字段说明。
- **预设**：新增预设与提示词条目，编辑、排序、开关和删除；支持台词格式、插入位置、深度、系统/用户/助手身份及发送预览。角色绑定独立于预设。
- **音频收藏**：保存、筛选、重听和删除喜欢的对白；也可管理普通缓存。
- **相册**：导入本地照片、查看、删除和设为壁纸。
- **备忘录**：手动记录、编辑和保存文本。
- **听取**：查看最近一条回复中的中文台词，逐句或整条播放，暂停、继续、停止和收藏。
- **设置**：默认台词语言、系统日夜、音量、悬浮/声波开关、缓存清理、壁纸、图标与可跳过锁屏。

顶部灵动岛显示当前播放状态；点右上角或向下拖动打开控制中心；底部横条回桌面。应用草稿在本次面板会话内保留，完成编辑后点击保存。侧键可显示锁屏；锁屏默认关闭，可随时跳过。信号与电量图标为外观装饰。

## 开始朗读

1. 在「引擎」填写并保存自己的 API Key，选择模型和服务区域。
2. 在「角色」为实际说话者绑定音色，选择语言并保存。
3. 在「预设」选择要使用的提示规则，回酒馆正常发送聊天。
4. 回复中带有完整语音标签后，点击台词旁的声波生成并朗读。

语音只在点击播放或试听后生成，可能消耗对应服务账户额度。未知角色会等待选择音色，保存后可继续。读取公开音色成功不代表密钥有效。

正文显示完整中文译文和声波，原语言文本保留在消息数据里用于朗读。声波跟随酒馆主题，区分未生成、可播放和已播放；播放时读取真实音频强弱，再次点击可暂停/继续。已播放标记保留到本次插件关闭，刷新后的缓存显示为可播放。

悬浮入口可以拖动并贴边收起。点击细条先展开为球，再点球进入设置；设置中可以关闭悬浮入口或声波动效。整条播放等总控位于扩展入口与听取 App。

## 保存与资料

已有密钥、角色三引擎绑定和预设沿用原有保存位置。密钥存于当前浏览器，按酒馆账户隔离；换浏览器、酒馆地址或清除网站数据后需要重新填写。

参考音频、收藏、照片、备忘录和手机个性化使用当前浏览器的本地资料库，重新打开可恢复。资料不会随 GitHub 更新同步到其他设备。清理普通语音缓存会保留收藏、照片、备忘录和参考音频。

普通缓存上限 200 MiB，按旧记录清理；本地资料总上限 256 MiB，达到上限会提示失败。单张照片上限 12 MiB，参考音频上限 20 MiB。浏览器实际可用空间可能更少。删除照片时会清理使用它的壁纸/图标引用。资料内容不自动送入聊天提示词。

## 台词格式

```text
“{译文}”<tts role="{角色}" emotion="{情绪}">{文本}</tts>
```

格式允许编辑，四个字段各出现一次，字段之间及首尾需有固定分隔符。提示词中的 `{{格式}}` 和 `{{语言}}` 在发送时替换。预设可统一设置插入方式，条目可独立覆盖；深度和身份仅在「聊天内」插入时生效。

发送时附加各角色模型规则与完整对白、双语逐句对应要求。模型仍可能漏标或漏译，需在实际聊天中观察。代码块、不完整标签和 `{角色}` 等占位符不会加入朗读队列。

## 环境与参数

目标为 SillyTavern 1.19.0 或更新版本，需提供消息格式钩子等启动检查中的接口。通过 localhost 或 HTTPS 打开酒馆；浏览器需支持 ES modules、Web Audio、IndexedDB、Web Crypto 和 AbortSignal.any。

插件直接访问官方语音服务，网络、账户区域、套餐、音色和模型权限影响实际可用能力。参数目录基于 2026-09-25 的官方文档快照；暂未接入当前通道的 Fish drama-3-preview 和 ElevenLabs v3 Conversational 不可选。MiniMax fluent/whisper 对应 2.6，声音动作标签对应 2.8；MiniMax 流式响应收齐后播放，字幕响应暂未接成查看功能。

播放器支持排队句序和真实声波，暂未提供音频秒级拖动定位。不支持的浏览器音频格式会提示改选 MP3 或 WAV。
