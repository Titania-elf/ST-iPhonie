# ST-iPhonie

版本 0.3.0，SillyTavern 浏览器扩展（原名 ST-TTS）。

酒馆里的一部小手机：给角色配音（Fish Audio、MiniMax、ElevenLabs），用 NovelAI 在正文里出图，还有听取、音频收藏、相册和备忘录。晴空贴纸风，日夜跟随系统；真手机上全屏打开。

## 安装与更新

在酒馆「扩展 → 安装扩展」粘贴：

https://github.com/hey8v0/ST-iPhonie

已经安装旧版 ST-TTS 的用户，直接在扩展管理里更新，然后刷新酒馆页面；角色、密钥、预设和本地资料都会保留（旧仓库链接会自动跳转）。在扩展设置里打开「ST-iPhonie → 打开小手机」，或点屏幕边上的悬浮球。无需额外安装 Termux 服务或 Node 模块。

## 手机里的 App

- **听取**：Galgame 对话框式播放器，逐句或整条播放、暂停、收藏；遇到没配音的角色会停下来，并带你去选音色。
- **绘图**：NovelAI 工作台。画风预设（画师串、固定正面、固定负面）、提示词与“从剧情生成”、多角色与位置、模型/尺寸/步数/CFG/采样器/种子、免费档守卫；生成的图可插入正文、设为壁纸，自动存进相册。
- **角色**：角色卡片与配音证件卡；三家引擎各自记住音色和模型；可填写外貌 tag，出图时自动补上。
- **引擎**：信用卡式卡包，三家语音引擎加 NovelAI；密钥、模型和全部参数；NovelAI 卡显示订阅档位和 Anlas 余额。
- **预设**：配音、聊天、绘图三类，各自独立。绘图预设是给正文模型看的出图规则。聊天预设随聊天 App 开放。
- **音频收藏、相册、备忘录、设置**：收藏与缓存分开保存；导入照片、设壁纸；便签式备忘录；主题、壁纸与图标、悬浮球、声波、正文出图开关。

桌面可左右滑动，第二页留给以后的新 App。顶部灵动岛显示播放状态，状态栏可下拉出控制中心，侧键可看锁屏（默认关闭，可跳过）。

## 配音

1. 在「引擎」填写并保存自己的 API Key，选择模型和服务区域。
2. 在「角色」为实际说话者绑定音色，选择语言并保存。
3. 在「预设 → 配音」选择提示规则，回酒馆正常聊天。
4. 回复中带有语音标签后，点台词旁的声波生成并朗读。

语音只在点击播放或试听后生成，会消耗对应服务的额度。台词格式：

```text
“{译文}”<tts role="{角色}" emotion="{情绪}">{文本}</tts>
```

正文只显示中文译文和声波，颜色跟随酒馆主题：虚线小点 = 角色还没配音；淡色 = 未生成；引号色 = 可以播放；引号色加底色 = 正在播放；下划线色 = 已播放。

## 正文出图

1. 在「引擎 → NovelAI」填写 Persistent API Token（pst- 开头）。插件直接连接 NovelAI，不经过酒馆。
2. 在「绘图」设置画风；在「角色」给角色填外貌 tag。
3. 打开「正文出图」（设置、预设的绘图页或绘图 App 都能开）。

之后模型会在正文里写 `<img prompt="英文 tag" characters="角色名">`。插件把画风固定串、标签内容和出场角色的外貌 tag 一起交给 NovelAI，图片出现在标签位置，并上传到酒馆的图片文件夹，换设备打开同一聊天也能看到。

新回复只在免费档内自动出图（Opus 无限小图：不超过 28 步、1024×1024）；超出免费档或读不到订阅时显示「点击生成」，会扣 Anlas 的生成每次都会先询问。免费档守卫默认开启。Vibe 参考图暂未支持。

## 保存与资料

密钥存于当前浏览器，按酒馆账户隔离；换浏览器、酒馆地址或清除网站数据后需要重新填写。参考音频、收藏、照片、备忘录和手机个性化保存在当前浏览器的本地资料库，不会随 GitHub 更新同步到其他设备；正文里出的图保存在酒馆服务器上。清理语音缓存会保留收藏、照片、备忘录和参考音频。资料内容不自动送入聊天提示词。

## 环境

SillyTavern 1.19.0 或更新版本；通过 localhost 或 HTTPS 打开酒馆；浏览器需支持 ES modules、Web Audio、IndexedDB、Web Crypto、DecompressionStream 和 AbortSignal.any。
