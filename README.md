# ST-TTS · 角色对白

版本 0.1.4，SillyTavern 浏览器扩展。

角色对白手动朗读，支持 Fish Audio、MiniMax、ElevenLabs 按说话者混用。中文译文供阅读，原语言台词供语音生成。提示词预设支持多条内容、插入位置、深度与系统/用户/助手身份；角色配音全局独立保存。

## 使用

1. 在酒馆扩展设置打开「ST-TTS · 角色对白」。
2. 进入引擎连接，选择服务区域和模型，在连接设置填写 API Key，点击保存密钥。
3. 在角色配音添加说话者，填写或读取音色 ID，选择语言并保存。
4. 选择提示词预设，正常发送聊天。生成带完整标签的回复后，点击单句播放或整条播放。
5. 未配置说话者会暂停，保存配音后继续。每个角色分别记住三家引擎的音色和模型，切换后恢复；更改后点击保存配音。
6. 角色编辑底部可删除角色配音，删除前会显示确认。格式占位符如 `{角色}` 不会被加入朗读队列。

密钥保存在当前浏览器的本地存储中，按酒馆账户隔离，刷新后自动恢复；换浏览器或清理浏览器数据后需重新填写。引擎连接页可单独清除密钥。密钥不进入角色、提示词预设或 GitHub。参考音频文件也只保留到页面关闭；设置保留文件名称，下一次需重新选择文件。点击播放会请求对应服务并可能消耗账户额度。

台词旁的声波按钮随酒馆主题变色，区分未生成、可播放和已播放；播放时随音频起伏。再次点击正在播放的声波可暂停，点击暂停中的声波可继续。已播放标记保留到本页关闭，刷新后已有缓存显示为可播放。

## 悬浮播放器

悬浮球可以拖动，松手后吸附到左右边缘，闲置收成细条，点边条先展开为球，再点球打开插件设置。整条播放、暂停和停止位于插件入口与「听见这一刻」。播放时音波读取实际音频强弱，暂停后停止。通用设置提供「显示悬浮播放器」「播放音波动效」两个独立开关；开关与位置会保存。日夜和引擎配色沿用插件设置，系统减少动态效果优先生效。

## 手机安装

1. 在手机酒馆打开「扩展 → 安装扩展」。
2. 粘贴仓库链接：https://github.com/hey8v0/ST-TTS
3. 安装完成后刷新页面，在扩展设置中打开「ST-TTS · 角色对白」。
4. 填写引擎密钥，配置角色音色，然后点击试听。

这是纯浏览器扩展，无需额外安装 Termux 服务或 Node 模块。后续可在酒馆的扩展管理中检查更新，更新后刷新页面。

## 环境

- 目标 SillyTavern 1.19.0 或更新版本，并提供 `SillyTavern.getContext().messageFormatter.addHook`。启动时检查所需接口。
- 请通过 localhost 或 HTTPS 地址打开酒馆。
- 浏览器需支持 ES modules、Web Audio、IndexedDB、Web Crypto 和 AbortSignal.any；手机浏览器的实际兼容性待真机验证。
- 浏览器直接访问官方语音服务。网络环境、账户区域、套餐和模型权限决定实际可用能力。

## 台词格式

默认：

```text
“{译文}”<tts role="{角色}" emotion="{情绪}">{文本}</tts>
```

格式允许修改，四个字段各出现一次，字段之间及首尾需有固定分隔符。字段内容中的分隔符用 HTML 实体转义。代码块和不完整标签不朗读。消息正文不被改写，标签仅在显示时转换成中文译文和声波按钮，原语言文本留在消息数据中用于朗读，不显示原文折叠栏。

发送时会为当前预设附加完整对白和双语逐句对应规则，沿用预设的插入位置、深度与身份。已有自定义提示词不被覆盖。模型仍可能漏标或漏译，规则效果需在后续对话中验证。

## 参数范围

引擎设置提供当前官方 TTS 文档的模型、声音、输出、发音词典和相关请求选项。界面小 i 标出限制。MiniMax 的流式响应收齐后播放。Fish 参考音频通过兼容接口传送；S1 用圆括号语气标签，S2 用方括号。MiniMax fluent/whisper 使用 2.6，语气词标签使用 2.8。

Fish drama-3-preview 与 ElevenLabs v3 Conversational 尚未验证当前合成通道，因此生成前明确报错，不发送请求。不支持的模型参数不发送；套餐受限项仍需账户验证。原始 PCM、A-law/μ-law 转成 WAV 后交给浏览器，其余格式由浏览器解码，不支持时提示改选 MP3 或 WAV。
