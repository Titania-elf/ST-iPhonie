# ST-iPhonie

版本 0.6.1，SillyTavern 浏览器扩展（原名 ST-TTS）。

酒馆里的一部小手机：和角色私聊、拉群聊天，给角色配音（Fish Audio、MiniMax、ElevenLabs），用 NovelAI 在正文里出图，还有听取、音频收藏、相册和备忘录。三套主题风格可换，日夜跟随系统；真手机上全屏打开。

## 安装与更新

在酒馆「扩展 → 安装扩展」粘贴：

https://github.com/hey8v0/ST-iPhonie

已经安装的用户，直接在扩展管理里更新，然后刷新酒馆页面；角色、密钥、预设和本地资料都会保留（旧的 ST-TTS 仓库链接会自动跳转）。在扩展设置里打开「ST-iPhonie → 打开小手机」，或点屏幕边上的悬浮球。无需额外安装 Termux 服务或 Node 模块。

## 手机里的 App

- **聊天**：和剧情里的角色私聊，或者拉群聊天；剧情之外的人可以手动添加成联系人。配好音色的角色会发语音消息，点一下才生成。输入框左边的「＋」里有照片、表情、红包、转账、位置、拍一拍、骰子和让TA说；长按消息可以引用、撤回。选中几条消息点「带进剧情」，下一次正文就会接上这段聊天。
- **听取**：Galgame 对话框式播放器，逐句或整条播放、暂停、收藏；遇到没配音的角色会停下来，并带你去选音色。
- **绘图**：NovelAI 工作台。画风预设（画师串、固定正面、固定负面）、提示词与“从剧情生成”、多角色与位置、模型（含 V5）/尺寸/步数/CFG/采样器/种子、免费档守卫；生成的图可插入正文、设为壁纸，自动存进相册。
- **角色**：角色卡片与配音证件卡；三家引擎各自记住音色和模型；可填写外貌 tag，出图时自动补上。
- **引擎**：信用卡式卡包，三家语音引擎加 NovelAI；密钥、模型和全部参数；NovelAI 卡显示订阅档位、Anlas 余额和 V5 免费额度。
- **预设**：配音、聊天、绘图三类，各自独立。
- **音频收藏、相册、备忘录、设置**：收藏与缓存分开保存；导入照片、设壁纸；便签式备忘录；主题风格、日夜、壁纸与图标、悬浮球、声波、正文出图开关。

桌面可左右滑动，第二页留给以后的新 App。顶部灵动岛显示播放状态，状态栏可下拉出控制中心，侧键可看锁屏（默认关闭，可跳过）。

## 主题风格

设置 → 主题风格：晴空贴纸（默认）、Frutiger Aero 和文艺小清新，每套都有日夜两版和配套壁纸。文艺小清新是米白信纸、灰绿和豆沙粉，标题用宋体，角落有一枝压花；壁纸白天是水彩草坡和淡淡的太阳，夜里是月亮和暗色草地。用自己的照片当壁纸时，换主题不会换掉照片。以后会再加新主题。

## 聊天

1. 在「聊天」点右上角加号，选一个角色私聊，或勾选几个人建群。联系人来自角色 App；剧情之外的人可以在「联系人」里手动添加并写上人设。
2. 点纸飞机只是把消息发进聊天窗口，可以连着发好几条。输入框空着时，纸飞机会变成气泡按钮「让对方回复」，点它才把这些消息交给酒馆当前连接的模型，对方一起回复（「＋」里的「让TA说」也一样）。回复会参考角色卡、你的用户设定、最近几条正文和聊天记录，但不会写进正文。
3. 想让一段聊天影响剧情：点「带进剧情」，选好消息，再点「带进下一次正文」。这段聊天只注入下一次正文生成一次，之前可以随时取消。

**「＋」里的功能**（对方也会用：「预设 → 聊天」里的「手机功能」规则告诉模型什么时候该发照片、位置、红包、转账或拍一拍你，你发的红包转账收不收按人设来，一轮最多用一次。这条规则可以改或关掉）：

- **照片**：从相册选一张，或者从本地选，再写一句说明。对方看不到图片本身，只看得到这句说明，所以写清楚照片里有什么。对方发来的「照片」是一张写着画面描述的拍立得卡片。
- **表情**：常用表情和颜文字，点一下插进输入框。
- **红包 / 转账**：填金额和祝福语（转账只在私聊里有）。对方收不收看人设；对方发来的红包点一下就能拆，转账可以收款或退还。钱都是剧情里的，不涉及真实支付。
- **位置**：填地点和详细地址，发一张地图卡片。
- **拍一拍**：私聊直接拍对方，群聊选一个人；双击聊天里的头像也能拍。
- **骰子**：掷一个 1–6 点的骰子。
- **让TA说**：不发消息，直接让对方（或群里）说话。

长按（电脑上右键）一条消息：引用它来回复、撤回自己发的（撤回的文字可以「重新编辑」），或者删除。

**语音消息**：平时只显示语音条，点一下播放；长按选「转文字」才显示文字。右上角「⋯ → 语音消息」可以选转出来显示中文译文、原文，还是原文和译文都显示，也可以让所有语音自动转文字。撤回和领取红包这类动作也会写进聊天记录，对方会知道。

「预设 → 聊天」可以改回复口吻、读取多少条正文和聊天记录、带进剧情的写法和插入位置。聊天记录保存在当前浏览器。

## 配音

「设置 → 配音 → 正文语音」是总开关，默认打开。关掉后，聊天请求里不再加入语音规则，模型只写普通对白；正文里已有的语音标签只显示中文译文，不显示声波；手机聊天里的联系人也只发文字。

1. 在「引擎」填写并保存自己的 API Key，选择模型和服务区域。
2. 在「角色」为实际说话者绑定音色，选择语言并保存。
3. 在「预设 → 配音」选择提示规则，回酒馆正常聊天。
4. 回复中带有语音标签后，点台词旁的声波生成并朗读。

语音只在点击播放或试听后生成，会消耗对应服务的额度。默认台词格式（成对标签，不带属性）：

```text
“{译文}”<tts>{角色}|{情绪}|{文本}</tts>
```

旧版的 `<tts role="…" emotion="…">` 写法仍能识别，旧聊天里的声波不受影响；还在用旧默认格式的预设会自动换成新格式。

正文只显示中文译文和声波，颜色跟随酒馆主题：虚线小点 = 角色还没配音；淡色 = 未生成；引号色 = 可以播放；引号色加底色 = 正在播放；下划线色 = 已播放。

## 正文出图

1. 在「引擎 → NovelAI」填写 Persistent API Token（pst- 开头）。插件直接连接 NovelAI，不经过酒馆。
2. 在「绘图」设置画风（画师串、固定正面、固定负面）；在「角色」给角色填固定外貌 tag。
3. 打开「正文出图」（设置、预设的绘图页或绘图 App 都能开）。

**配图方式**（绘图 → 正文出图，两种可切换）：

- **回复后单独配图**（默认）：正文模型只管写故事。回复写完后，插件用同一个模型单独再请求一次，读这条回复、挑出画面、写好出图块，再把图插到对应段落后面。出图规则不挤占正文，张数和格式更稳，每条回复多一次请求。
- **正文里顺手写**：出图规则加进正文请求，模型写故事时顺手写出图块，只要一次请求。

**出图块**：每张图一块，场景和每个人分开写，全部用英文 danbooru tag：

```text
<img>
画幅：竖 / 横 / 方
场景：分级、人数（单人加 solo，情侣加 hetero/yuri/yaoi）、时代、具体到摆设的地点和道具、状态和氛围、景别+视角+景深、光线、色调
角色：名字｜衣服和状态、姿势、写到身体部位和对象的动作、表情、视线｜不要出现的 tag｜站位（画面里每个人一行）
新外貌：名字｜固定外貌 tag（新角色第一次入画时写）
</img>
```

例：`角色：夏尔｜boy, cravat, sitting, holding teacup, 1.2::furious::, open mouth, glaring｜smile, calm, female｜C3`。

- 最要紧的一两个 tag 写成 `1.2::tag::` 加重（1.1–1.4）。
- 「不要出现的 tag」只对这个人生效，比如在发火就写 smile, calm；多人同框时插件会给每个人补上 fused bodies。
- tag 里不写人名，别人一律写 another（arms around another's neck）；两个人之间有方向的动作用 source#、target#、mutual# 双方都标上。
- 「张力」规则让模型挑动作最满的一刻、用最强的动作说法、情绪激烈时用 dynamic angle 和 dramatic lighting。
- 站位是 NovelAI 的 5×5 格：A–E 从左到右，1–5 从上到下，C3 正中间；不写就让模型自己摆。

插件把画风固定串接在场景前面；每个角色行前面自动补上角色 App 里的固定外貌（1girl 会换成 girl，人数只放在场景里），连同反向 tag 和站位交给 NovelAI 的多角色提示词；画幅决定横图、竖图还是方图。0.6 以前写的「名字｜tag｜一句英文」旧写法照样能读。新角色第一次入画时，模型写的「新外貌」会自动存进角色 App，之后每张图都照着画，长相保持一致，你也可以随时改。

默认出图规则（预设 → 绘图，每一条都能改或关掉）要求：挑不同的瞬间；地点写到摆设和道具，手里的东西必须写；景别只写一个，可加角度和景深，关键动作必须在镜头里；光线和色调由模型补全；每个人都要有表情和视线，而且用真实存在的 tag，情绪可以叠写和加重；每个人写上容易画错的反向 tag；没改过的旧版默认规则会自动换成新写法，自己改过的保持不变；镜头外的身体部位不写；多人互动用 source# / target# / mutual# 标出谁对谁做；已有作品里的角色把识别 tag 放最前；画面里有什么必须来自正文和设定，不加人、不加剧情、不编天气。

每条回复出几张图是固定的（1–10 张，默认 1 张），在出图规则里改。出图块留在聊天记录里（图片靠它显示），但「发给模型时去掉旧出图块」开着时，之后每次请求模型都会把它们去掉，省下上下文。旧版的 `<img>tag|角色名</img>` 和 `<img prompt="…">` 写法仍能识别。

**看图和管理**：正文里只显示铺满的图片，不带文字和按钮。点图片会在原来的大小上弹出来，再用滚轮、双指或按钮随意放大缩小，拖动看细节，双击在原大小和 2.5 倍之间切换，单击隐藏或显示上下两条栏。其他的都在查看器里：左上「参数」看模型、尺寸、种子、角色和出图块；底部可以重画、在绘图中打开、收起、删除这版。重画会多出一个版本，旧图保留，用 ‹ › 前后对比，停在哪一版正文就显示哪一版；删除只删当前这一版（文件也从酒馆删掉）。收起后只留一个小缩略图；「正文图片默认收起」打开后，新图一出来就是收起的。「设置 → 存储」可以一次清除当前聊天的正文图片，或清除相册里的绘图。图片上传到酒馆的图片文件夹，换设备打开同一聊天也能看到。

**排队**：一个 NovelAI 账号同一时间只能画一张，同时请求会得到 429，太频繁还可能被风控。插件里所有出图排成一队，一张画完再发下一张（同一个浏览器里开的几个酒馆页面也会互相等），两张之间留间隔（默认 3 秒）；遇到 429 会等一会儿再试，每次等得更久（默认重试 4 次）。排队中的图在正文和绘图 App 里都能看到位置，也能取消。

**云端队列**：几个人共用一个 NovelAI 账号时，可以让所有人排同一条队，前面有人在画就先等。在「绘图 → 参数 → 云端队列」里选队列类型：

- **按密钥排队**：已经有的队列服务（比如智绘姬用的那个），填地址就行，不用房间码。用同一个 NovelAI 密钥的人自动排进同一条队，也能和用智绘姬的朋友一起排。插件只发送密钥的 SHA-256 摘要（算不回密钥）和随机编号。
- **房间码**：自己在 Cloudflare 免费部署的队列（步骤见 `cloud-queue/部署说明.md`），大家填同一个地址和房间码；有人撞上 429 时全房间一起等。

队列服务都看不到密钥、提示词和图片；连不上时照常出图，退回本机排队。

免费档：Opus 订阅生效时，28 步以内、1024×1024 以内的单张图不扣 Anlas。V4.5 及更早的模型无限；V5 用一份会慢慢恢复的免费额度，额度用完后改扣 Anlas，引擎卡和绘图 App 会显示剩余百分比。新回复只在免费档内自动出图；超出免费档或读不到订阅时显示「点击生成」，会扣 Anlas 的生成每次都会先询问。免费档守卫默认开启。Vibe 参考图暂未支持。

## 和其他插件一起用

- **排除标签**：配音和出图都是规规矩矩的成对标签。别的插件（总结、记忆等）要排除这些内容时，排除标签填 `<tts></tts>` 和 `<img></img>`。
- **悬浮球收纳脚本**：悬浮球不再使用 Shadow DOM，收纳脚本可以复制它的图标；从收纳里点它会直接打开小手机。

悬浮球闲置几秒后会藏到屏幕边后面，只露出带小箭头的一角；点一下探出来，再点打开手机。

## 保存与资料

密钥存于当前浏览器，按酒馆账户隔离；换浏览器、酒馆地址或清除网站数据后需要重新填写。参考音频、收藏、照片、备忘录、手机聊天记录和手机个性化保存在当前浏览器的本地资料库，不会随 GitHub 更新同步到其他设备；正文里出的图保存在酒馆服务器上。清理语音缓存会保留收藏、照片、备忘录、聊天和参考音频。只有你点「带进剧情」的聊天消息会进入正文请求。

## 环境

SillyTavern 1.19.0 或更新版本；通过 localhost 或 HTTPS 打开酒馆；浏览器需支持 ES modules、Web Audio、IndexedDB、Web Crypto、DecompressionStream 和 AbortSignal.any。
