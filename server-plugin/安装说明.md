# LoRA 桥 · 要不要装

**先确认一下你需不需要它。** 打开小手机 → 绘图 → 切到 ComfyUI → LoRA 页签 → 「添加 LoRA」，如果列表能读出来，**就不用装**，这个文件夹可以无视。

需要装的只有两种情况：

1. ComfyUI 没加 `--enable-cors-header` 启动参数，浏览器不允许网页跨域读它（秋叶整合包默认带了这个参数，所以大多数人不需要）。
2. 你在手机或另一台电脑上开酒馆，ComfyUI 的地址只有酒馆那台机器连得上。

这两种情况下，由酒馆代读 ComfyUI。另一个办法是给 ComfyUI 加上 `--enable-cors-header`，二选一即可。

## 装法（一次，升级不丢）

1. 把 **这个 `server-plugin` 文件夹整个拷到酒馆目录下的 `plugins/` 里**，建议重命名为 `st-iphonie-lora`，最后是这样：

   ```
   SillyTavern/plugins/st-iphonie-lora/index.mjs
   SillyTavern/plugins/st-iphonie-lora/package.json
   ```

2. 打开酒馆目录下的 `config.yaml`，确认有这一行（没有就加上，通常本来就是 `true`）：

   ```yaml
   enableServerPlugins: true
   ```

3. 重启酒馆。启动日志里会出现 `Initializing plugin from .../st-iphonie-lora/index.mjs`。

4. 回到小手机 → 绘图 → LoRA → 「添加 LoRA」，点刷新。列表就出来了。

**和以前的补丁不一样：不用改酒馆的源码。** `plugins/` 不在酒馆的版本管理里（它在酒馆的 `.gitignore` 中），所以酒馆升级不会覆盖掉它，装一次就一直有效。

想卸载：把 `plugins/st-iphonie-lora/` 删掉，重启酒馆。插件会自己退回「浏览器直连」或「手填文件名」。

## 它到底做什么

只有两个接口，都是只读的：

| 接口 | 用途 |
|---|---|
| `POST /api/plugins/st-iphonie-lora/lm` | 转发一条对 ComfyUI 的只读查询（LoRA 列表、元数据、触发词） |
| `GET /api/plugins/st-iphonie-lora/file` | 转发一张 LoRA 缩略图 |

限制写死在代码里：

- 只转发白名单路径——Lora Manager 的 `/api/lm/*` 和 ComfyUI 的 `/object_info/LoraLoader`；带 `..` 的路径直接拒绝
- 只用 GET 访问 ComfyUI，不跟随跳转
- 不透传任何请求头（cookie、密钥都不会被带出去），也不回传 `set-cookie`
- 缩略图只接受图片类型，超过 24 MB 拒绝

**它不是通用代理**，没法用它访问 ComfyUI 以外的地址，也没法用它访问 ComfyUI 上白名单以外的接口。提示词、图片、密钥一概不经过它。

## 想要缩略图和自动触发词

还要在 ComfyUI 里装 **ComfyUI-Lora-Manager**（ComfyUI 管理器里搜 `Lora Manager`，装上重启）。它会把 LoRA 的封面、模型名、底模、标签、触发词都扫好存在本地，小手机直接读，不联网、不算文件指纹。

没装 Lora Manager 也能用，只是列表里只有文件名，触发词手动填。
